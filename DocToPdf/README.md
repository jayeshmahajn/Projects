# Document to PDF Converter

A Spring Boot application that converts various document formats to PDF using LibreOffice.

## Features

- Convert DOC, DOCX, XLS, XLSX, PPT, PPTX, ODT, ODS, ODP to PDF
- Modern, responsive web interface with drag & drop
- REST API for programmatic access
- Docker support for easy deployment
- File size limit protection (50MB)
- Production-ready configuration

## Supported Formats

- Microsoft Word (.doc, .docx)
- Microsoft Excel (.xls, .xlsx)
- Microsoft PowerPoint (.ppt, .pptx)
- OpenDocument (.odt, .ods, .odp)
- Rich Text Format (.rtf)
